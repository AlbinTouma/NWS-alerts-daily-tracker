# The National Weather Service

[The National Weather Service (NWS)](https://www.weather.gov/documentation/services-web-api) publishes critical forecasts, alerts, and observations, along with other weather data. 

The bash script uses curl to get weather data from NWS api and saves the information to the alerts.json. 

The alerts.json file contains 70,380 alerts from 16/10/2025 to 6/03/2026. 
The NWS-alerts-daily-tracker no longer collects data from the NWS.
